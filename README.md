🛒 Shopping Trends Analysis
📌 Overview

Analyzed customer shopping behavior using a dataset of 3,900 records to identify patterns in demographics, purchases, and preferences.

📂 Dataset
shopping_trends_updated.csv
3900 rows, 18 columns
🛠️ Tech Stack

Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly

🔍 Key Insights
Average customer age ≈ 44
Top categories: Clothing, Footwear, Accessories
Popular items: Blouse, Pants, Jewelry, Sandals
Avg spending ≈ $60 across categories
Debit/Credit cards show slightly higher spending
No missing data
🚀 Run
pip install pandas numpy matplotlib seaborn plotly
python analysis.py
